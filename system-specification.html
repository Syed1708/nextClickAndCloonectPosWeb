The platform features a decoupled, multi-platform REST architecture. The central Laravel API core powers a Next.js Web Client, a Touchscreen In-Store Kiosk, a Next.js Touch Web POS, a React Native Expo Mobile App, and real-time Kitchen Display Systems (KDS) synchronized via Laravel Reverb WebSockets.

⚙️ 2. Pillar 1: Laravel Backend Core & API Engine

  • Dual Authentication System: Decoupled authentication guards separating web customers (clients table) from staff, cashiers, and managers (users table managed by Tyro Dashboard).
  • OrderSync Engine (OrderSyncController.php): Handles bulk transaction payloads from Web POS, Kiosk, and Expo Mobile. Auto-assigns gapless sequential ticket numbers (1, 2, 3...) and prevents duplicate processing via UUIDs.
  • French NF525 Tax Compliance: Automatically calculates SHA-256 cryptographic hash chains (hash & previous_hash) during transaction commits to satisfy French tax regulations.
  • Stripe Payment Integration (StripeWebController.php): Secure payment session creation, fail-safe verification endpoint, and webhook listeners that auto-decrement raw ingredient inventory upon payment approval.
  • Automated Order Rejection & Refunds: 1-click order rejection automatically executes Stripe API Refund::create() and updates the customer live tracker with rejection reason notes.
  • Real-Time Broadcaster (Laravel Reverb): Pushes instant WebSocket events (KdsOrderUpdated & ReservationUpdated) to kitchen displays, hostess screens, and customer profile trackers.

💻 3. Pillar 2: Next.js Web Portal (App Router)

  • Click & Collect Portal (/order): Dynamic menu category filter chips, live search, 10-item pagination, floating cart badge, and slide-up item quantity sheet with promo code validation and loyalty points redemption.
  • Intercepted Product Details & Allergens (/product/[id]): Next.js 15+ Parallel Routes (@modal) and Intercepting Routes ((.)product/[id]) rendering product details in a modal overlay on click while preserving page state and scroll position.
  • Customer Live Tracker & Portal (/profile): Real-time Reverb WebSocket order tracking (pending_acceptance ➔ accepted ➔ preparing ➔ ready ➔ delivered), order history, table bookings manager, and profile updates.
  • Item Customization Modal (ItemModifierModal.tsx): Allows cashiers and customers to select cooking levels (Rare, Medium, Well Done), exclusions (No Onions), and paid suppléments (Extra Bacon +€1.50).
  • Global Store Status Guard: Automatically checks store status, operating schedules, and admin master toggles, disabling checkout buttons and rendering warning banners when ordering is closed.

📱 4. Pillar 3: Touchscreen Kiosk Terminal (/kiosk)

  • O'Tacos-Style Guided Step Builder: Middle-section step-by-step wizard (Size ➔ Cheese Sauce ➔ French Fries Placement ➔ Meats ➔ Sauces ➔ Extra Toppings ➔ Drinks) driven 100% dynamically from backend settings.
  • Customer Identification Screen: Customer inputs Name/Phone, enters Client ID, or scans a Loyalty QR Code before starting an order.
  • Smart Drink Combo Pricing Engine: Automatically applies discount pricing for soft drinks (€1.70 when ordered in a Meal Combo vs €2.10 A La Carte).
  • Flexible Payment Options: Choice between Pay by Card at Kiosk (Stripe Terminal) or Pay at Counter (Cash/Card at Register).
  • 10-Second Screen Reset: Displays a large ticket number (e.g. #T-102) and auto-resets to Attract Mode screen saver for the next customer.

📅 5. Pillar 4: Table Reservations & Hostess Management

  • Web Customer Self-Booking (/reservation): Select date, time, guest count, and dining zone preference (Indoor Room, Terrace, VIP Lounge) with 24/7 future booking support and schedule validation.
  • Table Collision Prevention: Automatically checks table capacity and blocks double-booking the same table within a 2-hour window.
  • Interactive Admin Floor Plan (/admin/reservations/floor-plan): Real-time visual table grid displaying green/amber/red status badges (AVAILABLE, RESERVED, OCCUPIED) and 1-click hostess guest seating actions.
  • Web POS Hostess Drawer (/pos/reservations): Cashier interface for viewing expected arrivals and recording fast phone call reservations.

📈 6. Pillar 5: Back-Office Operations, HRM & Financial P&L

📦 Supplier Purchases & Inventory

  • CSV Invoice Importer: Strictly validates supplier CSV invoices with PK binary magic-byte detection.
  • Auto-Stock Incrementing: Receiving a delivery automatically increments ingredient stock levels in base storage units (g, ml, units).
  • Auto Food Cost Expense: Automatically creates an Expense entry under food_cost category upon delivery.

🗑️ Food Waste & Loss Tracking

  • Inventory Loss Logging: Tracks spilled, expired, or damaged food.
  • Auto-Stock Decrementing: Automatically reduces ingredient stock levels upon logging waste.
  • Auto Waste Loss Expense: Calculates financial loss (qty × unit_cost) and posts a waste_loss expense.

👨‍🍳 HRM & Multi-Region Payroll

  • Contract Hours Tracking: Supports 35h, 39h, and 42h weekly contracts for French CDI/CDD/Extra & UK staff.
  • Total Employer Cost: Tracks Net Pay + Employer Charges (Cotisations Patronales / NI) to capture true labor expense.
  • Auto-Payroll Expense: Marking payroll as paid automatically posts a salaries expense.

📊 Executive P&L Financial Dashboard

  • Real-Time Net Profit Calculation: Automatically calculates Net Operating Profit and Profit Margin Percentage:

    • Net Profit = Net Sales (HT) - Food Costs - Waste Losses - Labor Costs - Operating Overhead

👨‍🍳 7. Pillar 6: Kitchen Display System (KDS) & Dispatcher

  • Chef Screen (chef.blade.php): Listens on kds-channel via Reverb WebSockets. Plays a dual-tone audio alert on new orders. Displays high-contrast badges (🛍️ ONLINE ORDER (TAKEAWAY) vs 🍽️ DINE-IN), customer names, and pulsing bright yellow callout boxes for item instructions ("⚠️ NO ONIONS | EXTRA BACON").
  • Packer Screen (packer.blade.php): Tracks kitchen preparation status (Waiting for Kitchen, In Preparation, READY), provides item verification checkboxes (⬜ / ✅), and triggers completion (Served / Delivered).
  • Online Orders Dispatcher (/admin/orders/online-management): Continuous Uber-style chime alarm with 1-click ETA buttons (15m, 30m, 45m), automated Stripe refunds on rejection, and right-side live stats panel.

🎟️ 8. Pillar 7: Customer Loyalty & Promo Code Engine

  • Promo Codes / Coupons: Supports percentage OFF (10%), fixed amount OFF (€5.00), minimum order thresholds (€20+), expiration dates, and global usage limits.
  • 1-Time Per Customer Safeguard: Automatically verifies customer history to ensure single-use welcome codes (`WELCOME10`) cannot be reused by the same client.
  • Loyalty Points Engine: Automatically awards 1 point per €1 spent on completed orders. Logged-in customers with 100+ points can redeem 100 points for an instant €5.00 discount during checkout.
